RTA Scripter

طريقة التشغيل:
1. افتح index.html في المتصفح.
2. لإضافة سكربتات جديدة، افتح scripts.js.
3. أضف عنصرًا جديدًا داخل مصفوفة scripts.
4. ضع رابط صورة في image إذا أردت.
5. ضع كود السكربت في script.

للنشر:
- ارفع الملفات الأربعة إلى GitHub Pages أو Netlify أو Vercel.
- لا تحتاج قاعدة بيانات لهذه النسخة.

ملاحظة:
هذه نسخة Front-End فقط. إذا أردت لوحة تحكم تضيف السكربتات من الموقع نفسه، تحتاج Backend وقاعدة بيانات.
